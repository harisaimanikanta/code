# రెండో జీవితం - v3, motivational-speaker style with an example (2026-11-27)
Style follows the orator-style references Y1 (14.1M) and Y4 (727K) in `telugu-reference-analysis.md`:
- the speaker promises an answer ("చెప్తాను"),
- asks the audience rhetorical questions,
- gives one vivid example,
- builds commands in threes,
- ends on a contrast punchline.

The example is the well-known "86,400 bank account" parable, presented as an imagine-this exercise, not as a true story.
A day has 86,400 seconds (24 × 60 × 60).

మనందరికీ రెండు జీవితాలు ఉంటాయి.
రెండోది ఎప్పుడు మొదలవుతుందో తెలుసా?
చెప్తాను... కానీ ముందు ఒక్క నిమిషం... ఊహించుకో.

ప్రతి రోజు పొద్దున్నే నీ అకౌంట్ లో ఎనభై ఆరు వేల నాలుగు వందల రూపాయలు పడతాయి.
ఒక్కటే రూల్.
రాత్రి పన్నెండు అయ్యేసరికి... ఖర్చు పెట్టనిదంతా పోతుంది.
ఒక్క రూపాయి కూడా మిగలదు.
అప్పుడు నువ్వేం చేస్తావ్?
ప్రతి రూపాయి వాడుకుంటావ్ కదా?

అలాంటి అకౌంట్ నీ దగ్గర ఉంది.
దాని పేరు... సమయం.
రోజుకి ఎనభై ఆరు వేల నాలుగు వందల సెకన్లు.
ఈ రోజు వాడుకోనిది... రేపు తిరిగి రాదు.

కానీ మనం ఏం చేస్తాం?
రేపు చూద్దాం. తర్వాత చేద్దాం. టైం వచ్చినప్పుడు.
అమ్మకి ఫోన్... రేపు. ఆ కల... తర్వాత. ఆ సారీ... టైం వచ్చినప్పుడు.

ఇంకో నిజం చెప్పనా?

నీకు తెలీదు. నాకు తెలీదు. ఎవ్వరికీ తెలీదు.

ఇది అర్థమైన రోజే... నీ రెండో జీవితం మొదలవుతుంది.

## Delivery (speaker mode)
| Part | Lines | Voice |
|---|---|---|
| Hook | రెండు జీవితాలు… తెలుసా? | Calm, confident, like a speaker on stage; real question |
| Promise | చెప్తాను… ఊహించుకో | Lean in, lower the voice: draw the audience close |
| Example | 86,400 రూపాయలు… ఒక్కటే రూల్… | Storyteller pace; stop before "ఖర్చు పెట్టనిదంతా పోతుంది" |
| Audience question | నువ్వేం చేస్తావ్? … కదా? | Pause 1 s as if waiting for an answer |
| Reveal | దాని పేరు… సమయం. | Long pause before "సమయం"; say it quietly |
| Mirror | రేపు చూద్దాం… టైం వచ్చినప్పుడు | Mock-lazy voice; then slower and sadder on అమ్మకి ఫోన్ / కల / సారీ |
| Truth | నీకు తెలీదు ×3 | Three hits, slower each time |
| Answer to the hook | ఇది అర్థమైన రోజే… | Warm, clear: the moment it clicks |
| Commands | బతుకు! అడుగెయ్యి! ఉండు! | Rising energy, one beat each (like Y1's "లే! బయలుదేరు!") |
| Punchline | ఎన్నేళ్లు… ఎలా బతికామన్నదే ముఖ్యం. | Drop the music; slowest line; land hard on "ముఖ్యం" |

Length: about 115 Telugu words → about 45–50 s with pauses (Y1, the 14.1M reference, is 48 s).
Visual: speaker to camera (or faceless with a stage-mic sound feel). Captions line by line. Show "86,400" big on screen at the
reveal. Build the BGM like Y1: soft strings that rise to the commands, then silence before the punchline.
