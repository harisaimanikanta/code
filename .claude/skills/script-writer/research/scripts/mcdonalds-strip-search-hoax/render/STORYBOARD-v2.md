# V2 storyboard: "The Phone Call" (141.2 s, 9:16, original voiceover unchanged)

Every voiceover line gets its own shot, and each shot shows what that line says.
Shots run 1.5–5 s. Each shot uses one slow camera move (push, pull, pan or hold).
Cuts land on the gaps between lines. Fades are used only when the location changes.

**Camera key:**
- WS: wide shot
- MS: medium shot
- CU: close-up
- ECU: extreme close-up
- OTS: over-the-shoulder
- POV: point of view

**Fixed visual rules:**
- **The caller:** always the same dark room, the same silhouette and the same phone. We see him only in cutaways when he is talking.
- **"Officer Scott":** his authority is a police-cap shadow that appears only behind whoever is holding the receiver. It disappears on Tom's "NO" and never comes back.
- **Louise:** she stays on screen through the ordeal, so the viewer keeps following her.
  - She is never shown nude. The clothes come off in shots framed from behind at shoulder height.
  - After that she is wrapped in an apron, which is historically accurate.
- **Walter's assault:** never shown. We see a closed door and the blinds being lowered.
