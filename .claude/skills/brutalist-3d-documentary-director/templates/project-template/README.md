# Brutalist documentary project

Generated by the `brutalist-3d-documentary-director` skill. Everything is data-driven:

- `data/shot-plan.json` — one continuous camera move per entry (no cuts), lighting, sound cues
- `data/world-layout.json` — the single connected 3D world (zones, objects, actors, occluders, anchors)
- `data/subtitles.json`, `data/production-config.json`
- `src/library/` — vendored studio assets pinned by `asset-lock.json`; `src/project-assets/` — project-only

```bash
npm install
npm run bake          # compile the camera track
npm run studio        # interactive preview (Remotion Studio)
SKILL=<path to skill>
$SKILL/scripts/render-project.sh . stills          # QC stills
$SKILL/scripts/render-project.sh . preview 300 600 # preview clip (half res)
$SKILL/scripts/render-project.sh . full            # final MP4 (+ validation)
```
